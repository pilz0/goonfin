# goonfin

Fork of [jellyfin-web](https://github.com/jellyfin/jellyfin-web) for the goon cave.

- `src/themes/goon` — neon pink default theme
- `branding/` — logos and favicons; edit `branding/src/*.svg` and run `branding/render.sh`
- `src/strings` — Jellyfin renamed to Goonfin, en-us gooned up

Branches: `main` = goon changes on top of an upstream release tag. To update, rebase onto the new tag.
